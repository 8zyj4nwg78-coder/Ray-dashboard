# Ray Builders Project Controls

Phone-first project-controls app for Ray Builders jobs (Oakhurst Synagogue, Paramount Office, Deal Kollel, plus any you add).

- `index.html` is the entire app: plain HTML/CSS/JS with no build step.
- Data is saved in the browser on the device you use it on (localStorage). Use **Settings → Copy backup** to keep a copy.
- It is published as a private claude.ai artifact. The file is written for the artifact host, which adds the `<!doctype>`/`<head>` wrapper.
